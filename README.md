# pankajbhattarai.com.np

Personal academic website of Pankaj Bhattarai, Ph.D. student in Computer Science at Florida State University.

The whole site is a single static page, `index.html`, served with GitHub Pages at <https://www.pankajbhattarai.com.np/>.

- `assets/CV.pdf`: CV linked from the page
- `assets/photo.jpg`: profile photo, used as the link-preview image
- `CNAME`: custom domain for GitHub Pages
